<h1 align="center">MicroHRM - HUMAN RESOURCE MANAGEMENT SYSTEM.</h1>

The HRM system is a cutting-edge Human Resource Management platform designed with a Micro Frontend architecture. It is composed of multiple independent modules, each capable of being developed, tested, and deployed autonomously, while seamlessly integrating into a unified application. This modular design ensures high flexibility, scalability, and maintainability, allowing teams to work concurrently on different parts of the system without disrupting the overall user experience. Users benefit from smooth navigation across all modules, consistent functionality, and a cohesive interface, making the HRM system ideal for organizations seeking efficient, modern, and adaptable human resource management solutions.
